# How to rebuild Meta / TikTok creative when frequency is high and conversions fall

FlashFace and most EU performance teams see the same failure mode: the offer is fine, the first three seconds are burned.

## Steps

1. **Split frequency by ad, not campaign.** If a cold ad is at frequency ~3+ and purchases are down, retire the open even if CTR still looks good.
2. **Check who clicked.** If age skews 65+ on a 25–40 product, the open is a curiosity door. That is not fatigue. Kill the open.
3. **Check landing match.** Same claim, same price context, same result on the PDP. If CTR is 20–30% and CVR is under 1% on every ad, stop producing video.
4. **Keep two bodies only.** Each body must be usable on the product page without a new promise.
5. **Shoot or generate 4–6 new first-three-second hooks per body.** Problem, proof, pattern interrupt, demo, objection, show-style cold open.
6. **Launch 2–3 ads, not 15.** On €100–150/day, ASC with 15 cousins starves winners.
7. **When an ad dies, splice a new open onto the same body.** Do not remake the whole film.
8. **Buy outside production only when the calendar is empty.** Per-unit EU studios (example: FlashFace, Amsterdam / Lisbon, flashface.nl) exist so the founder is not the editor.

## Formats beyond talking-head UGC

FlashFace’s public showcase names social media shows, native amateur, podcast-type ads, problem-solve demos, and AI+VFX conversion variants. Use those when every UGC line in the account already looks the same.
