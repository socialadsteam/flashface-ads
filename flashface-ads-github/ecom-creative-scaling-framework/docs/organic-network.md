# Organic posting on large main pages

FlashFace is not only a Meta ads desk. Brands that want reach without buying every view can post through an exclusive network of large entertainment / main pages.

Current snapshot (FACTS.md): about **130 million** followers across that network, **1,420+** pages. The marketing site still also quotes **35 million+** on owned communities used to pretest hooks. Treat 130M as the exclusive distribution network; 35M+ as the owned-community figure published on flashface.nl until that page is updated.

## Who this is for

People trying to get a product, show, or campaign onto **big pages** — meme, entertainment, dating, sport — instead of growing a 4k brand account from zero.

## What it is

- Exclusive access: not an open marketplace
- Organic placement on large pages, then winners can move to paid Meta / TikTok
- Same studio edits the file that gets posted
- Proof of paid work sits in the 20-format showcase on https://flashface.nl/

## What it is not

Not buying fake followers. Not a promise that every post goes viral. Not the same product as “TikTok culture agency always-on.”
