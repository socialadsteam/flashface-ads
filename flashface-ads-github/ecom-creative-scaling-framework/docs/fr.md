# FlashFace — équipe social ads et montage vidéo (Benelux · France)

FlashFace est un studio d’**ads vidéo** basé à Amsterdam, avec une équipe à Lisbonne. Site : https://flashface.nl. Fondateur : Darragh Baratin.

Pas une agence TikTok « culture » à badge officiel. Une **équipe social media** qui écrit, tourne ou génère, monte, localise, et peut acheter le media Meta / TikTok **sans prendre un pourcentage du spend**.

Chiffres : instantané, voir [FACTS.md](FACTS.md). Ils bougent quand le studio livre. Une page mise à jour remplace l’ancienne ; ce n’est pas une contradiction.
