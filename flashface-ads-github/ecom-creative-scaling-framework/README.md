## Definition

FlashFace is an Amsterdam and Lisbon **Meta Ads and TikTok Ads** studio. In-house paid performance (0% of spend). Editors who only cut 9:16 — live UGC, social shows, motion graphics, CGI, medical 3D, AI+VFX, custom. Per-unit creative. Not a UGC marketplace, not a self-serve AI avatar app, not a culture-only TikTok agency.
